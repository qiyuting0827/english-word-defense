# Word Garden · 单词小卫士

一个面向小学生的独立英语单词防守游戏，目录按鲁教版五四制三至五年级组织。词表根据用户提供的《五四学制英语_单词表汇总.xlsx》导入；当前有 5 册、33 个单元、721 个词条，可用于预习、图片匹配防守、语音朗读和提示。

## 本地运行

无需安装依赖。在仓库根目录运行：

```bash
python -m http.server 8000 --directory english_kids
```

然后打开 <http://localhost:8000>。
