# 单词守卫队 · 英语词汇小游戏

一个面向小学生的独立英语单词防守游戏，目录按鲁教版五四制三至五年级组织。词表根据用户提供的《五四学制英语_单词表汇总.xlsx》导入；当前有 5 册、33 个单元、721 个词条，可用于预习、词义匹配防守、语音朗读和提示。

每局可选 6、10 或 15 个单词，并可在三种匹配玩法间切换：

- **经典**：敌人显示英语，卡片显示图片和英语标签。
- **汉译英**：敌人显示中文释义，卡片显示英语单词。
- **英译汉**：敌人显示英语单词，卡片显示中文释义。

开战前可选择怪物来袭速度（50%–100%，默认 60%；同时调整怪物移动和出现间隔），并会先展示本局随机抽到的确切单词及释义。预告词会与本局卡片和敌人保持一致；更改单元或每局词数时重新抽取。

## 在线使用

GitHub Pages：<https://qiyuting0827.github.io/english-word-defense/>

应用支持添加到手机主屏幕；首次联网打开后可缓存应用外壳供离线使用。完成的对局记录默认只保存在本机。只有主动生成或输入同步码后才会启用云端同步；同步码是数据钥匙，请妥善保管，不要使用姓名等个人信息作为同步码。

## 本地运行

无需安装依赖。在仓库根目录运行：

```bash
python -m http.server 8000
```

然后打开 <http://localhost:8000>。
